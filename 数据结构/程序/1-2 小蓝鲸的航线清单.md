### 题目描述

小蓝鲸正在整理两片海域的巡游航线编号。每片海域的编号都按从小到大的顺序记录在一条**单链表**中，且同一条链表中不会出现重复编号。

为了规划接下来的巡游，小蓝鲸需要得到两份新的编号清单：

- **交集清单**：同时出现在两条链表中的编号；
- **并集清单**：至少出现在一条链表中的编号。

请你根据两条有序单链表，按从小到大的顺序输出它们的交集和并集。

对于一个编号：

- 当且仅当它同时出现在两条链表中时，它属于交集；
- 只要它出现在至少一条链表中，它就属于并集；
- 每个编号在交集和并集中都至多输出一次。

两条链表均可能为空。若某个结果清单为空，输出 `EMPTY`。

### 输入格式

第一行包含两个整数 `n` 和 `m`，分别表示第一条链表和第二条链表的结点数。

第二行包含 `n` 个整数 `a1, a2, ..., an`，按链表从头到尾的顺序给出第一条链表中的编号。当 `n=0` 时，该行为空行。

第三行包含 `m` 个整数 `b1, b2, ..., bm`，按链表从头到尾的顺序给出第二条链表中的编号。当 `m=0` 时，该行为空行。

保证每条链表中的编号严格递增。

### 输出格式

输出两行：

1. 第一行输出两条链表的交集清单，编号之间用一个空格分隔；若交集为空，输出 `EMPTY`；
2. 第二行输出两条链表的并集清单，编号之间用一个空格分隔；若并集为空，输出 `EMPTY`。

### 样例输入

```
5 5
1 2 4 7 9
2 3 7 8 10
```

### 样例输出

```
2 7
1 2 3 4 7 8 9 10
```

### 样例说明

编号 `2` 和 `7` 同时出现在两条链表中，因此交集清单为：

```
2 7
```

将两条链表中的所有编号合并并去重后，得到并集清单：

```
1 2 3 4 7 8 9 10
```

### 数据范围与约定

对于所有测试数据：

```
0 <= n, m <= 100000
-10^9 <= ai, bi <= 10^9
```

题目保证：

- 第一条链表中的编号严格递增；
- 第二条链表中的编号严格递增；
- `n` 和 `m` 可以同时为 `0`；
- 输入规模较大，建议在线性时间内完成操作。
