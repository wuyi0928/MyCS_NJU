### 题目描述

小蓝鲸正在模拟怪兽世界中的军团对战。这里有两支军团 `A` 和 `B`，每支军团最初都有 `n` 只怪兽。

- `A` 军团的怪兽依次编号为 `A1, A2, ..., An`，初始生命值分别为 `a1, a2, ..., an`；
- `B` 军团的怪兽依次编号为 `B1, B2, ..., Bn`，初始生命值分别为 `b1, b2, ..., bn`。

战斗按轮进行。一轮中的战斗和复活全部处理完毕后，如果至少一支军团中没有存活怪兽，整场战斗结束。

#### 每轮战斗

每轮开始时，两支军团的存活怪兽均按照编号从小到大排列，并从队首开始按对应位置两两战斗：

- `A` 军团第 1 只存活怪兽与 `B` 军团第 1 只存活怪兽战斗；
- `A` 军团第 2 只存活怪兽与 `B` 军团第 2 只存活怪兽战斗；
- 依此类推，直到至少一支军团没有尚未参加本轮战斗的怪兽。

如果一支军团的存活怪兽较多，多出的怪兽本轮不参加战斗。**每只怪兽在一轮中最多参加一次战斗**；即使它击败了对手，也不会在本轮继续攻击下一只怪兽。

#### 单场战斗规则

设 `A`、`B` 两只怪兽战斗前的生命值分别为 `x` 和 `y`：

- 若 `x > y`，`B` 怪兽被击败，`A` 怪兽的生命值变为 `x-y`；
- 若 `x < y`，`A` 怪兽被击败，`B` 怪兽的生命值变为 `y-x`；
- 若 `x = y`，两只怪兽同时被击败。

被击败的怪兽立即离开存活队伍，但这不会改变本轮开始时已经确定的配对关系。

#### 每轮胜负与连续失败

设本轮 `A`、`B` 军团被击败的怪兽数量分别为 `dA` 和 `dB`：

- 若 `dA > dB`，`A` 军团输掉本轮；
- 若 `dA < dB`，`B` 军团输掉本轮；
- 若 `dA = dB`，本轮为平局。

每支军团分别维护自己的连续失败轮数：

- 输掉本轮：连续失败轮数加 `1`；
- 赢得本轮：连续失败轮数清零；
- 本轮平局：两支军团的连续失败轮数均清零。

#### 三连败复活

如果一支军团连续输掉 `3` 轮，则在第 3 个失败轮结束后立即触发一次复活。

在该军团所有“已经被击败且从未复活过”的怪兽中，选择：

1. 初始生命值最大的怪兽；
2. 如果有多只怪兽初始生命值相同，选择编号最小的怪兽。

复活后的怪兽生命值恢复为初始生命值，并按照原编号重新插入存活队伍。它从**下一轮**开始才能参加战斗。每只怪兽最多复活一次；复活后若再次被击败，将永久离开战场。

触发复活后，无论是否存在能够复活的怪兽，该军团的连续失败轮数都清零。本轮刚刚被击败的怪兽也可以被本轮结束后的复活选中。

例如，可复活的怪兽为：

```
A2：初始生命值 15
A5：初始生命值 20
A7：初始生命值 20
```

应当复活 `A5`。如果复活前的存活队伍为

```
A1 -> A3 -> A6
```

那么 `A5` 复活后，队伍变为

```
A1 -> A3 -> A5 -> A6
```

#### 战斗结束

一轮中的全部配对战斗结束后，先统计本轮胜负并处理可能发生的复活，再判断整场战斗是否结束：

- 只有 `A` 军团还有存活怪兽：`A` 获胜；
- 只有 `B` 军团还有存活怪兽：`B` 获胜；
- 两支军团都没有存活怪兽：双方平局；
- 两支军团都还有存活怪兽：继续下一轮。

### 输入格式

第一行包含一个整数 `n`，表示两支军团最初各有 `n` 只怪兽。

第二行包含 `n` 个整数 `a1, a2, ..., an`，表示 `A` 军团怪兽的初始生命值。

第三行包含 `n` 个整数 `b1, b2, ..., bn`，表示 `B` 军团怪兽的初始生命值。

### 输出格式

输出四行：

1. 第一行输出最终结果：`A`、`B` 或 `DRAW`；
2. 第二行输出战斗进行的总轮数；
3. 第三行按编号从小到大输出 `A` 军团存活怪兽的**当前生命值**，以一个空格分隔；如果没有存活怪兽，输出 `EMPTY`；
4. 第四行按编号从小到大输出 `B` 军团存活怪兽的**当前生命值**，以一个空格分隔；如果没有存活怪兽，输出 `EMPTY`。

### 样例输入

```
4
3 8 2 1
2 5 1 9
```

### 样例输出

```
A
5
5
EMPTY
```

### 样例说明

第一轮共有四组怪兽战斗：

- `A1(3)` 击败 `B1(2)`，剩余生命值为 `1`；
- `A2(8)` 击败 `B2(5)`，剩余生命值为 `3`；
- `A3(2)` 击败 `B3(1)`，剩余生命值为 `1`；
- `B4(9)` 击败 `A4(1)`，剩余生命值为 `8`。

本轮 `A` 阵亡 1 只，`B` 阵亡 3 只，因此 `B` 输掉第一轮。此后，`A1`、`A2`、`A3` 依次在第 2、3、4 轮被 `B4` 击败，`A` 连续输掉三轮。

第 4 轮结束后，`A` 触发复活。尚未复活过的阵亡怪兽中，`A2` 的初始生命值最大，因此 `A2` 以 `8` 点生命值复活。

第 5 轮，`A2(8)` 击败 `B4(3)`，最终剩余 `5` 点生命值，`A` 军团获胜。

### 数据范围

对于所有测试数据：

```
1 <= n <= 2000
1 <= ai, bi <= 10^9
```
