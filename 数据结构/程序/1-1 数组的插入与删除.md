### 题目描述

小蓝鲸正在练习顺序存储结构。给定一个长度为 `n` 的整数数组。请依次执行 `k` 次插入或删除操作。所有位置从 `1` 开始编号。

设操作前数组长度为 `m`：

- `I p x`：将整数 `x` 插入第 `p` 个位置。原第 `p` 至第 `m` 个元素均向后移动一位，其中 `1 <= p <= m+1`；
- `D p`：删除第 `p` 个元素。原第 `p+1` 至第 `m` 个元素均向前移动一位，其中 `1 <= p <= m`。

移动次数只计算操作前已经存在、操作后仍保留在数组中的元素；新插入和被删除的元素本身不计入。

每次操作后，输出当前数组以及本次操作的移动次数。

### 输入格式

第一行包含两个整数 `n` 和 `k`，分别表示初始数组长度和操作数量。

第二行包含 `n` 个整数 `a1, a2, ..., an`，表示初始数组。当 `n=0` 时，第二行为空行。

接下来 `k` 行，每行是一条操作：

```
I p x
```

或

```
D p
```

### 输出格式

对于每次操作输出两行：

1. 第一行输出操作后的数组，元素之间用一个空格分隔；如果数组为空，输出 `EMPTY`；
2. 第二行输出本次操作的移动次数。

### 样例输入

```
5 4
10 20 30 40 50
I 3 99
D 5
I 1 7
D 6
```

### 样例输出

```
10 20 99 30 40 50
3
10 20 99 30 50
1
7 10 20 99 30 50
5
7 10 20 99 30
0
```

### 样例说明

- `I 3 99`：`30 40 50` 向后移动，移动次数为 `3`；
- `D 5`：`50` 向前移动，移动次数为 `1`；
- `I 1 7`：原有 `5` 个元素全部向后移动，移动次数为 `5`；
- `D 6`：删除末尾元素，无需移动其他元素。

### 数据范围与约定

```
0 <= n <= 1000
1 <= k <= 1000
-10^9 <= ai, x <= 10^9
```

题目保证所有位置合法，执行删除操作时数组非空，且操作过程中数组长度不超过 `2000`。

### 实现要求

请使用普通数组完成本题，不使用链表或标准库中的动态顺序容器（如 C++ 的 `std::vector`）。插入时移动元素腾出位置，删除时移动后续元素填补空缺。

### 输入输出提示

本题输出量较大。使用 C++ 时，建议关闭同步并解除 `cin` 与 `cout` 的绑定：

```
ios::sync_with_stdio(false);
cin.tie(nullptr);
```

输出换行时请使用 `"\n"`，避免使用会额外刷新输出缓冲区的 `endl`。
